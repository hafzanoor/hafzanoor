## Hi, I'm Hafza Noor 👋

Mathematician working on **medical image analysis** and **trustworthy deep learning** at Bahauddin Zakariya
University, Multan, Pakistan. I care less about getting a model to a high number and more about knowing
whether that number can be trusted: how a model is evaluated, how it fails on new data, and how optimization
and uncertainty methods can make it safer to use.

### Research interests
- Medical image segmentation and classification (MRI)
- Explainability, calibration and out-of-distribution robustness
- Optimization methods for machine learning and metaheuristic algorithms

### Featured work
| Project | What I found |
|---|---|
| [**Explainable Brain Tumor MRI Classification**](https://github.com/hafzanoor/MRI_Agent_Gradio) · [live demo](https://hafzanoor-brain-tumor-classification-agent.hf.space) | 95.2% test accuracy with MobileNetV2, but an audit showed **36% of test images duplicated training data**. On clean images accuracy drops to 92.8% and calibration worsens. Includes Grad-CAM, confidence-based human review and bootstrap confidence intervals. |
| [**3D Multimodal Brain Tumor Segmentation**](https://github.com/hafzanoor/Brain-Tumor-3D-Segmentation) *(in progress)* | 3D U-Net on four-channel MRI (FLAIR, T1w, T1gd, T2w) from the Medical Segmentation Decathlon, with a **patient-level** split so no patient appears in both training and testing. |
| [**Face Image Enhancement and Feature Matching**](https://github.com/hafzanoor/Face-Image-Processing-OpenCV) | Histogram equalization, Canny edges and ORB keypoint matching on 19,906 face images, with an honest look at where keypoint matching fails. |
| [**GDP Prediction with Multiple Linear Regression**](https://github.com/hafzanoor/Using-Multiple-Linear-Regression-model-for-predicting-economic-growth-indicators) | Shows why an R² of 0.9998 says more about an accounting identity (GNI ≈ GDP) than about predictive power. |
| [**Gradient Descent from Scratch**](https://github.com/hafzanoor/salary-prediction-gradient-descent) | Linear regression optimized with hand-derived gradients, no ML libraries. |
